## 🚀 Быстрый старт

### Локальная разработка
```bash
# Запустить локальный сервер
python -m http.server 8080

# Или с Node.js
npx serve .

# Откройте http://localhost:8080
```

### Развертывание на GitHub Pages

1. **Создайте репозиторий на GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/yourusername/portfolio.git
   git push -u origin main
   ```

2. **Активируйте GitHub Pages**
   - Перейдите в Settings → Pages
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
   - Сохраните

3. **Настройте форму обратной связи**
   - Зарегистрируйтесь на [Formspree.io](https://formspree.io/)
   - Создайте новую форму
   - Замените `your-form-id` в `index.html` на ваш ID

## 🎨 Анимации и эффекты

### Фоновые анимации
- **Градиентный фон**: 3 слоя с 20-секундным циклом
- **Светящиеся орбы**: 4 орба с разными анимациями (float, pulse, rotate)
- **Система частиц**: 50 частиц на десктопе, 20 на мобильных
- **Интерактивные эффекты**: Орбы реагируют на движение мыши

### Оптимизации
- Пауза анимаций при скрытой вкладке
- Учет `prefers-reduced-motion`
- Упрощенные эффекты на мобильных устройствах
- `will-change` для плавных анимаций

## 📧 Настройка формы обратной связи

### Вариант 1: Formspree (рекомендуется для GitHub Pages)
1. Зарегистрируйтесь на [Formspree.io](https://formspree.io/)
2. Создайте новую форму
3. Получите ваш Form ID
4. Замените `your-form-id` в `index.html`:
   ```html
   action="https://formspree.io/f/YOUR_ACTUAL_FORM_ID"
   ```

### Вариант 2: EmailJS (для локальной разработки)
Следуйте инструкциям в `EMAILJS_SETUP.md`

## 🎯 Кастомизация

### Изменение цветов
Отредактируйте CSS переменные в `styles.css`:
```css
:root {
  --accent: #6f7cff;      /* Основной акцент */
  --accent-2: #8f5bff;    /* Второй акцент */
  --bg: #070b14;          /* Фон */
  --text: #edf2ff;        /* Текст */
}
```

### Настройка анимаций
Измените параметры в CSS:
```css
.bg-orb {
  filter: blur(40px);     /* Размытие */
  opacity: .3;            /* Прозрачность */
}
```
